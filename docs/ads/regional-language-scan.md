# Regional Language Scan — Meta Ad Library

Covers Tamil, Telugu, Kannada, Malayalam, Bengali (Marathi is noted as not reliably
isolable — see bottom). Same India/active-ads scope as the main field scan. Short
version: **AstroLokal runs the identical ₹20-30 "money yog" hook in Tamil, Telugu,
Kannada, and Malayalam simultaneously** — it's the single heaviest, most consistent
creative pattern in this entire research effort, in any language. And **Mana Sastram
(Telugu) is a direct ₹199 clone of our exact product** — same price, same format, same
"plain language, not mystical" positioning.

## Bengali (কুষ্ঠি/জাতক = kundali/horoscope)

Structurally different market — **no flat-fee PDF report competitor found at all.**
Every result was either a local astrologer/priest offering phone or WhatsApp
consultations (Pijush AstroCare, Koyel Shastri, Sanjay Shastri), an astrology *course*
(₹2,499 to learn astrology, not get a reading), or a matrimony service bundling kushthi
matching into a ₹2,999+ registration package rather than selling it standalone. Daily
rashifal (horoscope) content marketing is common as a trust-building/engagement tactic
before the pitch. If we ever enter Bengali, this looks like underserved territory for a
flat-fee PDF — but also a market where the audience may be more consultation-conditioned,
so the "instant PDF, no call" pitch may need more trust-building around it than in Hindi/
Tamil/Telugu/Malayalam.

## Marathi — not reliably isolable via keyword search
Marathi shares Devanagari script and most kundali-related vocabulary with Hindi
("जन्म पत्रिका", "कुंडली" mean the same thing in both), so keyword search on the Ad
Library surfaces overwhelmingly Hindi-market advertisers with no way to confirm which
ones are actually targeting Marathi-speaking audiences specifically. This isn't a gap in
the research — it's a real limitation of the tool. **When we actually run Marathi
campaigns, target by geography (Maharashtra) + Meta's ad-language setting in Ads
Manager, not by scraping the public library for "Marathi" ads** — that's the reliable
way to isolate that audience, this scan method can't do it.

## What this changes

1. **Mana Sastram is the closest direct competitor found in this entire research
   effort** — same price (₹199), same format (PDF report, not consultation), same
   "plain language, not mystical jargon" positioning we're already using
   ("not chakras" in their English tagline is almost exactly our own "instant clarity,
   not a call" angle from `meta-ads-copy.md`). Worth periodically checking their ad
   copy/creative for what's still running/working, since they've clearly validated this
   exact price point in a regional market.
2. **AstroLokal's near-zero "first chat" hook is the single heaviest-spending creative
   pattern found across this entire scan** — Tamil (₹20), Telugu (₹20), Malayalam (₹20),
   and a variant via Lovish in Kannada (₹3). Same emotional question, same price shape,
   four languages, all running simultaneously. It's a consultation-upsell funnel, not a
   flat-fee report like ours, so it's not a direct copy target — but the pattern (name
   the money-yog question, price the first touch near-zero) is worth testing as a
   teaser-to-paid funnel once the free teaser feature ships (per
   `docs/prd/frontend-gap-plan.md` issue #20).
3. **Navagraha's audio-plus-PDF format (Malayalam, ₹249)** is the one genuinely novel
   differentiator found in this whole research effort — nobody else, in any language,
   pairs the PDF with a spoken explanation. Worth a mention as a future differentiation
   idea, not a sprint-2 priority.
3. **Free preview before paying** shows up again here (Mana Sastram: "Free chart, ₹199
   for the complete PDF") — this is the third independent confirmation across Hindi,
   English, and Telugu markets that "see something real for free, pay for the full
   report" outperforms a blind paywall. Our PRD's teaser feature is directionally
   correct; this is more evidence to prioritize shipping it.
4. **Should we localize ourselves?** Given how consistent the winning pattern is across
   four separate languages (near-zero first-touch price, one specific money question, an
   AI-chat or flat-fee-PDF funnel), this isn't really five separate markets requiring five
   separate strategies — it's one validated playbook that clearly transfers across
   language. That makes regional expansion lower-risk than it would otherwise look: the
   open question is translation + local payment/delivery norms (WhatsApp is the default
   delivery channel in every non-Hindi market scanned), not "does this angle even work
   here." Still not a fit for the current 2-week Hindi/Hinglish money-debt sprint — this
   is groundwork for the campaign structure doc (`regional-campaign-structures.md`) to
   act on once the sprint has a validated winner to translate.
