# Money/Debt Sprint — Ad Copy (2-Week Focus)

**Goal:** run this as the only angle for the next 2 weeks, ₹99–₹299 price ladder, before expanding to other angles from `campaign-plan.md`. Every variant below is tagged with the competitor pattern it's testing, sourced from the Meta Ad Library field scan (`docs/ads/campaign-plan.md` history + the Sep 2026 scan — see the published report for source ads).

**Landing page:** `/` (Money Kundali is already the default homepage angle).
**Disclaimer line, every ad:** "Astrological guidance, not financial advice." (keep in comment or landing page footer, per `meta-ads-copy.md` notes).

Price ladder to A/B across the 10 variants: **₹99 · ₹149 · ₹199 · ₹299 (anchored from ₹499)**. Don't run all four price points with all ten copy variants — pick 2-3 price points per week and let cost-per-purchase pick the winner (per `campaign-plan.md`'s existing "don't move on until you have a clean read" rule).

## Suggested 2-week test structure

| Week | Price points live | Copy variants | Budget split |
|---|---|---|---|
| 1 | ₹99, ₹199 | V1, V2, V4, V5, V8 (5 creatives) | ₹1,000/day, even split across 5 |
| 2 | Winner's price point + ₹299 anchor test | Top 2-3 from week 1 + V6, V9 | Reallocate toward the week-1 winner, keep 20% on new variants |

Kill anything that doesn't get a clean cost-per-purchase read in 3 days (existing rule from `campaign-plan.md`). V7 (English) should run as its own isolated test — different audience, don't let it dilute the Hindi/Hinglish comparison.
